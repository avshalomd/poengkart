# Lookup first, chance of a place as an opt-in layer

Poengkart carries two products: a trustworthy lookup of the poenggrenser the counties publish in PDFs and HTML tables, and a model that turns a family's points into a chance of a place. The model is the differentiator and the portfolio story, so the obvious choice was to lead with it. We decided (2 September 2026) that the map leads with the lookup, and the chance colouring is something the user switches on by entering points and reads a sentence about first. Reason: the lookup is undisputed fact from the counties; the chance is an estimate with documented weak spots (sparse history, intake-round mixing, optimism below about 60%), and a parent acting on it should have opted in knowingly. The model's numbers are still shown as the model produces them; this decision is about what leads, not about softening the output.
